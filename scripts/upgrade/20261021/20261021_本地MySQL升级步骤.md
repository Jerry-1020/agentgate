# MySQL 升级步骤

适用于本地 AgentGate 测评性能优化升级，数据库连接使用项目根目录 `.env` 中已有的本地 MySQL 配置。

## 1. 进入项目目录

暂停本地任务提交，停止正在使用该数据库的后端和任务工作进程，然后进入项目目录：

```bash
cd /Users/eric/hw/xql/pythonwork/agentgate
```

后续所有命令和路径均以项目根目录为基准，不需要进入 `scripts/upgrade/20261021/` 目录。

## 2. 升级数据库结构

```bash
.venv/bin/python scripts/upgrade/20261021/migrate_evaluation_summaries.py --apply --env-file .env
```

该命令添加缺失的摘要表、查询字段和索引。已经升级过结构、仅需回填历史摘要时，可以跳过本步。

## 3. 回填历史摘要数据

```bash
mkdir -p runtime/evaluation-summary-upgrade

.venv/bin/python scripts/upgrade/20261021/backfill_evaluation_summaries.py --apply --env-file .env --batch-size 50 --report runtime/evaluation-summary-upgrade/backfill.json
```

该命令根据已有数据集、任务、运行和评测结果生成摘要及查询字段，不重新执行评测，不修改原始结果或运行状态。回填报告保存在 `runtime/evaluation-summary-upgrade/backfill.json`。

## 4. 启动后端

启动命令为：

```bash
.venv/bin/python -m uvicorn agentgate.server.app:app --host 127.0.0.1 --port 8000 --env-file .env
```

每一步执行成功后再执行下一步。已有数据库使用上述迁移命令即可，不需要执行 `scripts/sql/init.sql`，也不需要再手动执行迁移 SQL 文件。
