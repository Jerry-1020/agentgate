# 测评集导入错误汇总与定位实施计划

> **For agentic workers:** 使用 subagent-driven-development 分工实施，逐项验证。

**Goal:** 将已有导入校验错误集中展示，并准确定位原文件，供修正后重新上传。

**Architecture:** 保持 parseSampleFile 成功返回值及保存接口不变；解析阶段保留源位置，使用结构化错误收集器汇总现有校验错误，向导负责展示和阻止错误文件保存。

**Tech Stack:** Vue 3、TypeScript、ExcelJS、Playwright。

## 约束

- 仅沿用现有格式校验，不新增业务必填、初始化变量校验。
- 不修改保存重试与部分成功语义，不引入新依赖。
- 错误明细最多展示 200 项，计数包含其余错误。
- 不可读取文件仅提供文件级错误；无效 JSON 单元格不产生后续格式连锁错误。
- Excel 保留原工作表、行、列；CSV 保留物理起始行；JSON 保留路径。
- 在「样本错误位置」列展示源位置，「问题与修改建议」列展示校验提示。

## 实施与验证

- [x] 编写结构化错误及原文件定位单元测试，确认旧实现失败。

- [x] 实现文件卡片、汇总、明细滚动区、重新上传和导入阻止。
- [x] 验证失败文件无保存请求、修正后重传成功、取消选文件状态不丢失。

- [x] 启动本分支前端并保留后端运行，提供访问地址。

## Review Focus

- 空行和单元格换行后位置保持真实文件行号。
- 多轮乱序和同一轮多条期望错误保持源位置。
- 超过 200 项时计数准确且页面可操作。
- 文件损坏不产生虚构字段错误。
- 失败、重新上传、部分保存重试不复用过期样本。

- 新增浏览器用例 5/5 通过，原手工新增向导回归 2/2 通过；桌面及 390px 窄屏已目视检查。
