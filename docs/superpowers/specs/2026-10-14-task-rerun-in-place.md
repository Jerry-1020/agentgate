# 单任务原配置重跑

用户已确认：任务不变，每次执行生成新运行，补齐测试并本地部署。

仅支持已完成、失败、取消的单任务；A/B、稳定性暂不开放。复用只读确认弹窗，不编辑、不选择最新版本。保留任务 ID、名称、创建时间和静态分析关联；历史运行、Trace、结果完整保留。执行使用新运行 ID，调度和目标适配器不变，凭证沿用原快照。

任务 `run_ids` 表示当前执行，新增默认空的 `previous_run_ids`。复用现有关联表，不迁移 SQL 结构。专用事务同时插入新运行和关联、更新任务当前执行；普通元数据保存不能改变当前运行或历史。

新增 `POST /api/evaluation-tasks/{task_id}/rerun`，请求 `source_run_id` 防止重复及过期提交。两个并发请求只能成功一次。拒绝活跃任务、分组任务、跨团队访问。派发失败保留已保存运行，沿用 waiting/retry。原运行级重跑 API 不变。

列表及任务详情默认展示最新运行，使用稳定任务 ID 导航，不新增列表行。删除任务覆盖所有当前和历史运行。总览的任务数不因重跑增加，执行样本数仍按实际执行计数。

本地验收使用独立 SQLite、明确标识的合成演示执行器，不连接行内服务或付费模型。没有 MySQL/BJS 环境时报告未联调。
